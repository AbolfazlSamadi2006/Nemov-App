# 🏋️ نرم‌افزار جامع مدیریت باشگاه بدنسازی و برنامه‌ریزی ورزشی — یلدا (Yalda v3.1.0)

نرم‌افزار جامع، مدرن و کاملاً فارسی **یلدا (Yalda)** نسخه **3.1.0** جهت مدیریت هوشمند باشگاه‌های ورزشی و بدنسازی، تشکیل پرونده تخصصی ورزشکاران، حسابداری و امور مالی باشگاه، ارزیابی آنتروپومتریک و سنجش فیزیکی، مدیریت مدارک پزشکی چندصفحه‌ای، و طراحی پیشرفته برنامه‌های تمرینی و غذایی همراه با پشتیبان‌گیری ابری و خروجی‌های متنوع (PDF، HTML تعاملی و Excel).

---

## ✨ قابلیت‌های کلیدی نسخه 3.1.0

### 🖥️ ۱. رابط کاربری واکنش‌گرا و تطبیق‌پذیر (Hybrid Responsive UI)
- طراحی کاملاً واکنش‌گرا و بهینه‌شده برای تمامی رزولوشن‌ها و ابعاد صفحه نمایش (**لپ‌تاپ‌های 1366×768، مانیتورهای عریض PC Full HD/2K/4K، تلویزیون‌های باشگاهی و Mac**).
- پشتیبانی کامل از مقیاس‌بندی DPI ویندوز (`PassThrough High-DPI`) و اسکرول هوشمند بدون بریدگی یا به‌هم‌ریختگی جداول و فرم‌ها.
- تم تاریک اختصاصی (**Dark-Red & Obsidian**) با چیدمان استاندارد راست‌به‌چپ (RTL) فارسی.

### 💰 ۲. امور مالی و حسابداری جامع باشگاه
- ثبت و مدیریت کامل تراکنش‌های مالی شامل **دریافت شهریه، تمدید اشتراک، درآمدهای جانبی و هزینه‌های جاری باشگاه**.
- فیلترهای زمانی هوشمند (**ماه جاری، سال جاری، کل دوره**) با محاسبه آنی **مجموع درآمدها، مجموع هزینه‌ها و تراز/سود خالص**.
- صدور صورت‌حساب و گزارش‌های مالی دقیق به دو فرمت **PDF استاندارد فارسی** و **اکسل (`Excel .xlsx`)**.

### 🔔 ۳. سامانه هوشمند اعلانات، سررسید شهریه و یادآوری‌ها
- پایش خودکار وضعیت اشتراک ورزشکاران و نمایش هشدار برای **سررسید شهریه فردا**، **موعد تمدید امروز** و **یادآوری سالروز تولد اعضا**.
- مرکز تاریخچه اعلانات با قابلیت **انتخاب چندتایی (`☑️ انتخاب همه / لغو انتخاب`)، حذف موارد انتخاب‌شده و حذف همگانی تاریخچه**.

### ☁️ ۴. مرکز پیشرفته پشتیبان‌گیری ابری، ایمیل و محلی (Backup & Cloud Sync)
- پشتیبان‌گیری کامل (`ZIP`) شامل دیتابیس و کلیه تصاویر پروفایل، مدارک پزشکی و رسانه‌های حرکات.
- **پشتیبان‌گیری در ۳ مقصد به انتخاب مربی:**
  1. ذخیره در حافظه کامپیوتر (Local)
  2. ارسال مستقیم به **سرور ابری اختصاصی یلدا (Cloud Server)**
  3. ارسال خودکار فایل پشتیبان به **ایمیل مربی**
- امکان **بازگردانی مستقیم از سرور ابری** یا فایل خارجی، به همراه جدول مدیریت آرشیوهای پشتیبان با قابلیت **انتخاب چندتایی، حذف گروهی و حذف همگانی آرشیو**.

### 🥗 ۵. برنامه‌ریزی هوشمند تغذیه، رژیم ایرانی و محاسبه BMR/TDEE
- محاسبه علمی و خودکار **متابولیسم پایه (BMR)** و **کالری تثبیت روزانه (TDEE)** بر اساس قد، وزن، سن، جنسیت و سطح فعالیت ورزشکار.
- تنظیم دقیق اهداف فیزیکی و محاسبه آنی سهم و درصد درشت‌مغذی‌ها (پروتئین، کربوهیدرات، چربی).
- بانک جامع ارزش غذایی خوراکی‌ها و غذاهای ایرانی با قابلیت جستجو، افزودن و ویرایش.

### 🏋️ ۶. برنامه‌ریزی تخصصی تمرینی و بانک حرکات چندرسانه‌ای
- طراحی برنامه تمرینی ۱ تا ۶ روز در هفته با امکان ذخیره و بارگذاری آنی از **بانک الگوهای آماده (Templates)**.
- بانک حرکات ورزشی مجهز به **تصویر و ویدیوی آموزشی** به همراه **ویرایشگر داخلی عکس (برش، چرخش، تنظیمات) و ویرایشگر ویدیو (برش بازه زمانی)**.
- صدور خروجی برنامه‌های تمرینی و غذایی در ۳ قالب:
  - 📄 **فایل PDF استاندارد و شکیل آماده چاپ**
  - 🌐 **فایل وب تعاملی (HTML) با قابلیت مشاهده تصاویر و ویدیوهای آموزشی حرکات**
  - 📦 **بسته فشرده جامع (ZIP)**

### 👥 ۷. پرونده جامع ورزشکاران، ارزیابی بدنی و مدارک پزشکی
- ثبت پرونده کامل اعضا به همراه عکس پروفایل (با قابلیت ثبت مستقیم از وب‌کم یا انتخاب فایل) و بازیابی سریع حذف‌های تصادفی (Undo Delete Banner).
- **ارزیابی آنتروپومتریک:** ثبت قد، وزن، درصد چربی، دور سینه، کمر، شکم، بازو، ران و ساق به همراه تاریخچه کامل تغییرات.
- **مقایسه بصری قبل و بعد (Before & After):** نمایشگر کنار هم جهت بررسی پیشرفت فیزیکی ورزشکار در طول دوره‌ها.
- **پرونده و مدارک پزشکی چندصفحه‌ای:** آپلود و مشاهده فایل‌های PDF و تصاویر آزمایش‌ها با قابلیت بزرگ‌نمایی و ورق زدن صفحات.

### 🔐 ۸. مدیریت چندمربی، امنیت و سیستم گزارش خطا (Diagnostics)
- تفکیک کامل اطلاعات و شاگردان هر مربی با سیستم ورود اختصاصی.
- بازیابی رمز عبور مربی از طریق **ارسال کد تایید به ایمیل** یا **کد ریکاوری مخفی**.
- پنل مدیریت ارشد جهت مدیریت حساب مربیان و سیستم ثبت خودکار لاگ‌های فنی (`System Error Logs`) با نمایشگر داخلی.

## 🛠️ تکنولوژی‌های استفاده‌شده

- **زبان برنامه‌نویسی:** Python 3.10+
- **رابط کاربری:** PyQt6 (طراحی RTL فارسی با معماری واکنش‌گرا و تم Dark-Red)
- **پایگاه داده:** SQLite + SQLAlchemy ORM
- **موتورهای خروجی و گزارش‌گیری:** ReportLab (PDF فارسی)، OpenPyXL (Excel)، HTML5/CSS3 Generator
- **پردازش تصویر، ویدیو و اسناد:** OpenCV (`cv2`)، Pillow، PyMuPDF (`fitz`)، ImageIO-FFmpeg
- **زیرساخت ابری:** Cloudflare Workers & REST Cloud Sync API
- **بسته‌بندی و ساخت نصاب:** PyInstaller + NSIS (`Yalda_Setup_v3.1.0.exe`)

## 👨‍💻 راهنمای اجرا در محیط توسعه (برای توسعه‌دهندگان)

۱. کلون کردن مخزن:
```bash
git clone https://github.com/AbolfazlSamadi2006/Yalda-Gym-App.git
cd Yalda-Gym-App
```

۲. ساخت و فعال‌سازی محیط مجازی:
```bash
python -m venv venv
.\venv\Scripts\activate
```

۳. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

۴. اجرای برنامه:
```bash
python main.py
```

## 📦 ساخت فایل اجرایی و نصاب (Build & Installer)

```powershell
# ۱. ساخت پوشه اجرایی مستقل با PyInstaller
.\venv\Scripts\pyinstaller.exe --noconfirm --clean Yalda.spec

# ۲. ساخت فایل نصاب ویندوز با NSIS
"C:\Program Files (x86)\NSIS\makensis.exe" installer.nsi
```
فایل نصاب نهایی در مسیر `dist\Yalda_Setup_v3.1.0.exe` تولید خواهد شد.
