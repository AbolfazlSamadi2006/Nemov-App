# ☁️ راهنمای سرور ابری پشتیبان‌گیری نِمُو (Nemov Cloud Server)

این سرور اختصاصی جهت دریافت، ذخیره‌سازی، دسته‌بندی و مانیتورینگ آنلاین پایگاه‌داده‌های نرم‌افزار ورزشی نِمُو (Nemov) توسعه داده شده است.

---

## 🌟 امکانات سامانه:
1. **دریافت خودکار بک‌آپ‌ها:** با شناسه یکتای شماره موبایل هر مربی (phone).
2. **جلوگیری از اشغال فضا:** هر بک‌آپ جدید جایگزین نسخه قبلی همان مربی می‌شود تا فضای سرور بهینه بماند.
3. **امنیت بالا:** ارتباط با توکن امنیتی اختصاصی (X-API-Key).
4. **پنل مدیریت تحت‌وب زیبا:** با تم تاریک/قرمز نرم‌افزار نِمُو، نمایش کارت‌های آمار و دکمه دانلود ۱-کلیک دیتابیس مربیان.

---

## 🚀 روش‌های راه‌اندازی و استقرار:

### روش اول: استقرار ۱۰۰٪ رایگان روی Cloudflare Workers (پیشنهادی ⭐️)
کد ورکر داخل پوشه `cloudflare_worker/index.js` قرار دارد و با اتصال به دامنه اختصاصی `nemovapp.ir` به صورت آنی و خودکار سرویس‌دهی می‌کند.

### روش دوم: استقرار روی Render.com یا اجرای لوکال در کامپیوتر
1. با اجرای فایل start_server.bat یا دستور زیر در ترمینال:
   ```bash
   pip install -r requirements.txt
   uvicorn server:app --host 0.0.0.0 --port 8000
   ```
2. پنل مدیریت در آدرس: http://localhost:8000 در دسترس خواهد بود.
