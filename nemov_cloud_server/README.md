# ☁️ راهنمای سرور ابری پشتیبان‌گیری و مدیا نِمُو (Nemov Cloud Server)

این سرور اختصاصی جهت دریافت، ذخیره‌سازی، دسته‌بندی، ارسال پیامک و مانیتورینگ آنلاین پایگاه‌داده‌ها و رسانه‌های نرم‌افزار ورزشی نِمُو (Nemov) بر بستر **رانفلر (Runflare)** و **ابر آروان (ArvanCloud S3)** توسعه داده شده است تا بدون نیاز به فیلترشکن و با اینترنت داخل ایران به‌صورت پایدار سرویس‌دهی کند.

---

## 🌟 امکانات سامانه:
1. **دریافت خودکار بک‌آپ‌ها:** با شناسه یکتای شماره موبایل هر مربی (`phone`) و نگهداری در فضای ابری آروان.
2. **میزبانی ویدیو و تصاویر تمرین‌ها:** ذخیره و پخش مستقیم مدیای حرکات تمرینی روی ابر آروان (`s3.ir-central1.arvanstorage.ir`).
3. **درگاه متمرکز پیامک (SMS.ir Gateway):** مدیریت اعتبار پیامکی مربیان و ارسال الگوهای خدماتی از طریق سرور رانفلر و پایگاه‌داده PostgreSQL.
4. **امنیت بالا:** ارتباط با توکن امنیتی اختصاصی (`X-API-Key`).
5. **پنل مدیریت تحت‌وب:** مدیریت نسخه‌های پشتیبان، رسانه‌ها و حساب‌های پیامکی مربیان.

---

## 🚀 راه‌اندازی و استقرار:

### روش اصلی (تولید): استقرار روی رانفلر (Runflare) + فضای ابری آروان
کد سرور اصلی داخل پوشه `runflare_app/` قرار دارد (`main.py`, `db.py`, `s3_storage.py`, `templates_renderer.py`) و به دامنه‌های رسمی `nemovapp.ir` و `storage.nemovapp.ir` متصل است:
```bash
cd runflare_app
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

### اجرای محلی (توسعه و تست):
```bash
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8000
```
پنل مدیریت در آدرس `http://localhost:8000` در دسترس خواهد بود.
